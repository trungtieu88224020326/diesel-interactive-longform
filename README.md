# Diesel — Interactive Longform Prototype

A React + Vite interactive editorial prototype based on the VnExpress article published 10 October 2026:
https://vnexpress.net/thi-truong-dau-se-ra-sao-sau-thoa-thuan-diesel-giua-nga-va-my-5130590.html

## Run

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (usually http://localhost:5173).

Production build: `npm run build`.

## Features
- Responsive 1440px desktop-first editorial layout
- Scroll-triggered chapter reveal and reading progress
- Interactive 4-step timeline
- Indexed bar visualization of reported +70% and -5% price changes
- Interactive diesel supply rerouting SVG diagram
- Expert commentary cards
- Interactive conditional scenario explorer
- Reduced-motion support

## Editorial note
This is an independent design prototype, not an official VnExpress product. The illustration, charts and scenarios are conceptual. The source article mixes tonnes and barrels in its supply figures; no conversions or aggregates have been fabricated. Quotes in the expert cards are paraphrases, not verbatim quotations. Confirm all figures and rights before publication.
